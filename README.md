# kidicode-Future-Genius-LMS-code
Kidicode Future Genius LMS FYP

This document explains how to set up and run the project locally using XAMPP.
Requirements
•	XAMPP (Apache & MySQL)
•	Web browser (Chrome, Firefox, etc.)

**Installation Steps**
1.	**Copy Project Folder**
    o	Copy the complete project folder.
    o	Paste it inside:
    o	XAMPP → htdocs
2.	**Start XAMPP Server**
    o	Open XAMPP Control Panel
    o	Start:
    	Apache
    	MySQL
3.	**Import Database**
    o	Open browser and go to:
    o	http://localhost/phpmyadmin
    o	Create a database (if not already created).
    o	Import the database file:
    o	kidicode.sql
4.	**Run the Project**
    o	Open your browser and type:
    o	http://localhost/Final
    Note: Final is the project folder name.
